## 8 附：六爻的起卦方法
### 第一个步骤：摇卦。
首先，准备三个一模一样的硬币，比如一元硬币，笔和纸：
（1）先记下当前时间，包括：年月日时；
（2）记下想预测的事情；
（3）找个安静的地方，手心中空，捧三个硬币摇几下，洒在桌面上，
（4）重复六次，依次记下每次三个硬币中出现“花面”的数量，如图“一”所示。第一行这种情况，是1个“花面”，记下“1”，第二行这种情况，是2个“花面”，记下“2”。
### 第二个步骤：排卦。

常见的六爻排卦软件很多，比如，“有道六爻排盘”，“六爻排盘宝”等，这里推荐使用前者进行排卦。

<img width="334" height="810" alt="image" src="https://github.com/user-attachments/assets/1ca72f92-e76f-4ac8-b96c-bc16bb1208a8" />

现在进行六爻排盘，如图二所示，
1. 首先输入信息，如：张三占该项目能否签约，
2. 刷新时间，
3. 选“手工指定”，
4. 由下到上，根据纸张记下的“花面”数量，依次选择每个爻的选项，一爻，二爻，以此类推，直到六爻。

注意，选项中的“1背”指的是1个硬币为“花面”，是第一次摇的，“0背”指的是0个硬币为“花面”，是第二次摇的，以此类推。

### 最后按下“查看卦象”按钮，便可以得到一个六爻卦了。

此步骤如果不会，也可以请卦师帮忙排卦。

好了，将上述得到的六爻卦画面拷屏，发给你的卦师，请他为你解卦。一般情况下，卦师帮忙看六爻的费用不高，但是如果涉及到六爻调理化解，则费用较高。

六爻是中国最常见的占卜方法之一，距今约有两千多年的历史。它的原理是利用易经的“五行生克制化”进行占卜。六爻常被应用于诸如：财、官、福、禄、寿、以及出行等具体事项的吉凶预测。大家不妨尝试一下看看。
